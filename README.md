# 宠物的一生 · 一爪一生

用十二分钟，陪一只动物过完它的一生。

这是《宠物的一生》的公开站点。纯静态 HTML/CSS/JavaScript，无后端、无账号、无广告。所有一生记录只保存在浏览器 localStorage。

- 站点：https://echo-ikun.github.io/petlife/
- 本地源项目：`default-workspace/petlife/`
- 灵感来自 [1in8b.life](https://1in8b.life/zh-hans/)，非官方作品。

## 玩法

选择九种动物之一，随机遇见六个家之一，做十一次选择，走完十一话。四项状态：健康、亲密、好奇、自在。十二种结局。结束后可以保存一张 1080×1440 的一生卡，或把这一生安放在回忆馆。

## 技术

- 原生 HTML / CSS / JS
- WebAudio 环境音
- Canvas 一生卡
- 响应式，手机/桌面同一个 URL
